# 데이터와 이용조건

- SGIS: 2024년 100m 인구, 집계구별 연령 인구, 2025년 2분기 행정경계
- 공공시설·편의점·경로당: 보고서와 `source_manifest.json`의 출처별 원본
- OpenStreetMap: 보행도로 정보. © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright)

원본과 연결된 인구 격자, 경로 거리 행렬은 공개 저장소에 포함하지 않았습니다. SGIS 이용조건을 확인해 원본을 확보하고 `code/data/raw/`에 준비한 뒤 공간 연결을 수행합니다.

`results/report_summary.json`은 최종 대안의 집계 결과이고, 선정 후보 CSV는 시설별 검토 목록입니다. 실제 설치 또는 기관 참여가 확정된 명부가 아닙니다.
